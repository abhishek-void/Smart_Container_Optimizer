# Smart Container Loading Optimizer

A simple DAA mini-project made with HTML, CSS and JavaScript.

## How to run
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Add items or click **Load sample**.
4. Set the container capacity and click **Optimize load**.

## Files
- `index.html` — page structure
- `style.css` — design and layout
- `script.js` — item management and optimization logic

## Sample check
Capacity: 50 kg
- Books: 10 kg, value ₹60
- Food boxes: 20 kg, value ₹100
- Equipment: 30 kg, value ₹120

Expected optimized value: ₹240, with 50 kg loaded.
